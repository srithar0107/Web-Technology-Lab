# Experiment 9 – Working with MongoDB Using Shell Commands

## Aim
To perform database and collection operations using MongoDB Shell (mongosh) for the Elite Architectural Firm.

## Software Requirements
- MongoDB Atlas
- MongoDB Shell (mongosh)
- Windows PowerShell

## Database Details
- Database Name: EliteArchitectureDB
- Collection Name: projects

## Description
This experiment demonstrates MongoDB database operations using MongoDB Shell. A database named EliteArchitectureDB and a collection named projects were created to store architectural project details.

## Operations Performed
1. Connect to MongoDB Atlas using mongosh.
2. Create and switch to the EliteArchitectureDB database.
3. Create the projects collection.
4. Insert architectural project records.
5. Display all project records.
6. Retrieve projects using find() and findOne().
7. Update project details using updateOne() and updateMany().
8. Count documents using countDocuments().
9. Delete selected records using deleteOne() and deleteMany().
10. Display database information using show dbs and db.stats().

## Result
Successfully performed MongoDB database, collection, insertion, retrieval, updating, deletion, and counting operations using MongoDB Shell for the Elite Architectural Firm.
